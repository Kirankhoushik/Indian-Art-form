# Indian-Art-form

Download the required artifact images into a local `images/` folder:

```bash
mkdir -p images
curl -L "https://upload.wikimedia.org/wikipedia/commons/3/32/Dancing_girl_of_Mohenjo-daro.jpg" -o images/dancing-girl.jpg
curl -L "https://upload.wikimedia.org/wikipedia/commons/4/4e/Sarnath_capital.jpg" -o images/lion-capital.jpg
curl -L "https://upload.wikimedia.org/wikipedia/commons/0/09/Sarnath_Buddha.jpg" -o images/sarnath-buddha.jpg
curl -L "https://upload.wikimedia.org/wikipedia/commons/3/3a/Shiva_as_Nataraja.jpg" -o images/nataraja.jpg
curl -L "https://upload.wikimedia.org/wikipedia/commons/0/0f/Mughal_miniature.jpg" -o images/mughal.jpg
curl -L "https://upload.wikimedia.org/wikipedia/commons/4/4e/Ravi_Varma_-_Galaxy_of_Musicians.jpg" -o images/raja-ravi-varma.jpg
```
